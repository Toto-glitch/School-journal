# Система электронного дневника школьника (WPF)

Проект системы электронного дневника для школы, разработанный на WPF с использованием Entity Framework 6 и SQL Server.

## Требования к заданию (Вариант 9)

### Логическая структура
- **Students** - ученики
- **Subjects** - предметы
- **Marks** - оценки
- **Teachers** - учителя
- **Parents** - родители
- **Users** - пользователи системы

### Ограничения
- Учитель может выставлять оценки только по своему предмету
- Оценки только в диапазоне от 1 до 5
- Родители могут просматривать только оценки своих детей

### Объем данных
- Учеников: 10
- Учителей: 5
- Оценок: 50
- Родителей: 10

### Обработка данных
- **Триггер**: при изменении оценки — запись в лог (MarkLogs)
- **Процедура**: выставление оценки (GradeService.SetGrade)
- **Запрос**: средний балл по предмету (GradeService.GetAverageMarkBySubject)
- **Подзапрос**: топ-3 лучших ученика (GradeService.GetTop3Students)

### Пользователи и права
| Роль | Права доступа |
|------|--------------|
| Директор | Доступ ко всем данным |
| Учителя | Выставление оценок |
| Родители | Просмотр только своего ребенка |
| Учащиеся | Просмотр дневника |

### Формы
- Авторизация
- Дневник ученика
- Выставление оценки
- Журнал

## Технологии

- **.NET Framework 4.7.2**
- **WPF** (Windows Presentation Foundation)
- **Entity Framework 6** (Code First подход)
- **SQL Server** (LocalDB или полноценный сервер)
- **MVVM паттерн** для разделения логики и UI

## Установка и запуск

### 1. Требования
- Visual Studio 2019 или выше
- .NET Framework 4.7.2 SDK
- SQL Server (Express или LocalDB)

### 2. Настройка подключения к БД

В файле `App.config` укажите строку подключения:

```xml
<connectionStrings>
  <add name="SchoolDiaryConnection" 
       connectionString="Data Source=(localdb)\MSSQLLocalDB;Initial Catalog=SchoolDiary;Integrated Security=True" 
       providerName="System.Data.SqlClient" />
</connectionStrings>
```

### 3. Сборка проекта

```bash
# Восстановление NuGet пакетов
nuget restore SchoolDiary.sln

# Сборка
msbuild SchoolDiary/SchoolDiary.csproj
```

### 4. Запуск

Откройте проект в Visual Studio и нажмите F5, или запустите исполняемый файл:

```bash
SchoolDiary\bin\Debug\SchoolDiary.exe
```

## Основные функции

### Для директора
- Просмотр всех данных системы
- Отчёты по классам и предметам
- Список лучших учеников
- Активность учителей
- Логи изменений оценок

### Для учителя
- Выставление оценок по своему предмету
- Редактирование и удаление своих оценок
- Просмотр журнала класса
- Средний балл по предмету

### Для родителя
- Просмотр оценок своего ребёнка
- Средний балл ребёнка
- Комментарии к оценкам

### Для ученика
- Просмотр своего дневника
- Оценки по предметам
- Средний балл

## Особенности реализации

### Триггер логирования
При любом изменении оценки (добавление, изменение, удаление) автоматически создаётся запись в таблице `MarkLogs` с указанием:
- Старого и нового значения
- Кто изменил (учитель)
- Дата и время изменения
- Тип операции

### Проверка ограничений
- Валидация диапазона оценок (1-5) на уровне модели и сервиса
- Проверка принадлежности предмета учителю перед выставлением оценки
- Фильтрация данных для родителей (только свой ребёнок)

### Гибкая навигация
- Единая точка входа через форму авторизации
- Автоматическое определение роли пользователя
- Динамическая загрузка соответствующего интерфейса
