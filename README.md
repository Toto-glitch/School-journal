# School Journal (Школьный журнал)

Приложение школьного журнала на базе WPF для управления учебным процессом.

## Описание

Это desktop-приложение для ведения школьного журнала, разработанное на WPF (.NET Framework 4.8). Приложение позволяет управлять:
- Студентами и группами
- Преподавателями и предметами
- Оценками и журналом успеваемости
- Дневником студентов
- Авторизацией пользователей

## Требования

Для запуска проекта необходимо установить:

1. **.NET Framework 4.8** или выше
2. **Visual Studio 2019/2022** (для сборки проекта)
3. **SQL Server Express** (обязательно!)

## Структура проекта

- `View/` — XAML представления (окна и страницы)
- `ViewModel/` — ViewModel классы (MVVM паттерн)
- `Model/` — Модели данных и инициализатор БД
- `Service/` — Сервисы для работы с данными, аутентификацией и командами
- `Converters/` — Конвертеры для WPF binding

## Технологии и пакеты

- WPF (.NET Framework 4.8)
- Entity Framework 6
- MVVM паттерн
- SQL Server
- Microsoft Data.SqlClient

## Данные для авторизации

При первом запуске приложения база данных автоматически заполняется тестовыми данными через класс `DatabaseInitializer`.

| **Преподаватель** | `teacher_petrova` | Преподаватель русского языка и литературы |
